# ホークアイ先生とあそぼ

**Hawkeye-sensei to Asobo** ("Play with Hawkeye-sensei") — soft tennis party games for one phone or tablet.
Two players face each other across the screen, play solo, or pass the device around. Each player picks their own level, so kids and adults can play together. Rules follow the official Soft Tennis Handbook 2026, with article numbers in the code.

- **Play:** https://omicreate.github.io/softtennis-asobi/ (Japanese, free, no install, works offline)
- **Stack:** React + TypeScript + Vite, PWA. Tests run on every push before deploying to GitHub Pages.
- **Soft tennis** is a racket sport played with a soft rubber ball, born in Japan.

*The rest of this README is in Japanese.*

スマホやタブレット1台で遊ぶソフトテニスのミニゲーム集。案内役は、ソフトテニスIQの公式キャラクター「ホークアイ先生」（鷹）。
遊び方は3つ：**むかいあう**（机に置いて2人で上下から同時に）、**ひとりで**、**てわたし**（1台を順番に回す。にせホークアイ先生・いしんでんしん・じゅんばんモード）。
子ども同士・親子・部員同士で遊べるよう、**レベルは1人ずつ選ぶ**（ちびっこ／キッズ／おとな／せんしゅ）。
アプリストアには出さず、Web ページを「ホーム画面に追加」して使う（PWA・オフライン可）。

- 公開先：https://omicreate.github.io/softtennis-asobi/ （`main` に push すると、GitHub Actions がテストを通してから公開する）
- 土台はピックルボールの「ピクルくんとあそぼ」（[pickle-asobi](https://github.com/omicreate/pickle-asobi)）。しくみ（舞台・レベル・ミッション・メダル・きねんカード・集計）は同じで、キャラ・道具・コート・ルール・問題をソフトテニスにした
- 部員・大人向けの「ソフトテニスIQ」（[softtennis-iq](https://github.com/omicreate/softtennis-iq)）とは別アプリ。おうちの方へ から案内する

## ゲーム（v0.1・10本）

| 遊び方 | ゲーム | 中身 | レベルの手加減 |
|---|---|---|---|
| ふたり | ラリーたいけつ | 指でラケットを動かして打ち合う。かんたん（何点先取）／ほんかく（4ポイント先取・デュース・1/3/5ゲーム、サービス2本・ダブルフォールト、ツーバウンズ、レシーブのダイレクト） | ラケットのとどく範囲、球の速さ、吸い寄せ |
| ふたり | はやタッチ | ちびっこ・キッズは、みどりに光ったら早押し。おとな・せんしゅは、ライン際の球やサービスがインかアウトかを判定して押す（ラインに触れたらイン） | 押せるまでの待ち時間、判定の問題のむずかしさ |
| ふたり | ホークアイ先生クイズ | こどもは絵と読み上げ（16問）、おとな・せんしゅはソフトテニスIQのルールドリル（128問・条番号つき）から早押し | 問題のむずかしさ |
| ひとり | ボールつき | ラケットでボールつき。何回続くか | ラケットの大きさ、はじめの球の高さ・飛ぶ距離 |
| ひとり | ねらって ストローク | ボールマシンの球を、光る的（正クロス・逆クロス・右ストレート・左ストレート）に打ち返す。10球で何球入るか | 的：ちびっこ＝相手コート全部、キッズ＝左右、おとな＝コース、せんしゅ＝コースの深い3m |
| ひとり | ホークアイの め（新作） | 上から見たコートを一瞬だけ見せ、消えたら「ボールはどこ？」「前衛はどこ？」「相手の陣形は？」に答える。10問 | 見せる時間（3秒〜1秒）、問題の種類 |
| ひとり | ホークアイ先生と ラリー | ホークアイ先生（コンピューター）と試合。ルールはラリーたいけつと同じ | ホークアイ先生の強さ＝選んだレベル |
| ひとり | リアクション ボレー | ボールマシンから球が出たらすぐタップ。オレンジの球はさわらない。5回の平均 | フェイント（おとな・せんしゅ） |
| みんな | にせホークアイ先生は だれだ？（3〜6人） | ワードウルフ型。1人だけお題がちがう。話しあいのあと ゆびさし／こっそり とうひょう。ばれても、みんなのお題を言い当てたら逆転 | お題：え／ことば／ソフテニ ようご（答えあわせで用語のちがいを条番号つきで出す） |
| みんな | いしんでんしん ダブルス（2人・4人） | 同じしつもんに、ペアの2人がこっそり答える。同じなら「いしんでんしん」。正解はない（作戦を話すきっかけ） | しつもん：え／なかよし／ダブルス さくせん（まめちしきは条番号つき） |

ホームの「おとなも むちゅう」には、クイズ・ホークアイの め・リアクション ボレーを出す。

**じゅんばんモード**（2〜6人・3か5ラウンド・ひとりずつ／チーム戦）：ひとりで遊ぶゲーム（ボールつき・ねらって ストローク・ホークアイの め・リアクション ボレー）を1人ずつ順番に遊び、記録で順位を決める。同じラウンドの人には同じ乱数の種を使うので、球や問題の並びが同じになる。チーム戦は「ホークアイ」と「ラケット」の2チーム。

**v0.2 以降の候補**：つなひき・エアソフテニ・ブロックくずし、ホークアイ先生 フライト・キャッチ、ラインぎわ ストップ・カーリング・よみあい サーブ・ピタッと10びょう・ジェスチャー、ホークアイ先生の小物（原画の表情がそろってから）

## ルールの根拠

ソフトテニスハンドブック 2026年版（日本ソフトテニス連盟）の競技規則。判定のコード・遊び方の説明（`src/shell/howto.ts`）・問題に「第〇条」を書いてある。条文は写さず、自分のことばで説明する。

| ルール | 条 | どこで使う |
|---|---|---|
| コートの大きさ（23.77m×10.97m、シングルスは8.23m）・サービスライン（ネットから6.40m） | 第5条・第6条、シングルス 第2条 | コートの絵、ラリー、ホークアイの め |
| ネットの高さ 1.07m・ポストの間 12.80m | 第10条 | ラリー |
| ボールは白いゴムの球（直径6.6cm） | 第15条 | 球の絵（硬式球に見えないように縫い目を描かない） |
| ラケットは長さ72cm以内・面の広さ120平方インチ以内 | 第16条 | ラケットの絵（`src/ui/paddleArt.ts`） |
| 4ポイント先取・デュース、ファイナルゲームは7ポイント | 第20条・第20条2 | ラリーのほんかく |
| フォールト・セカンドサービス・ダブルフォールト | 第27条・第27条2・第29条 | ラリーのほんかく |
| レシーブのダイレクトは失ポイント | 第32条(2) | ラリーのほんかく |
| ラインに触れた球はイン | 第36条2 | はやタッチ、ラリー |
| アウト・ツーバウンズ | 第37条(2)・(3) | ラリー |
| シングルスはゲームごとにサービスを交代、ファイナルゲームは2ポイントごと | シングルス 第4条、第34条2 | ラリーのほんかく |

## ミッション・きせかえ・共有・集計

- **きょうのミッション**：日付から毎日3つ決まる（かんたん／きろく／いっしょに）。1つ達成で ⭐1、3つ全部で ⭐+2。遊んだ日はスタンプになる（`src/core/missions.ts`・`progress.ts`）
- **きせかえ**：⭐と交換して、ラケットの色・もよう・かたちを集める。かたちはルールの大きさの中（第16条）。見た目だけで強さは変わらない。とくべつな色はスタンプ7こ・14こ、ミッション10こ、じゅんばんモード、メダル9こで もらえる（`src/core/items.ts`）。ホークアイ先生の小物は、原画の表情がそろうまで止めている（`WEAR_ON`）
- **きねんカード**：結果画面の 📸 から、名前の入らない画像（1080×1080）を作って端末の共有画面で送る。作る前に保護者の確認（かけ算）を出す（`src/ui/ShareSheet.tsx`・`shareCard.ts`）
- **じこベストと メダル**：ひとりで遊ぶ5本に、どう・ぎん・きん の目標。じゅんばんモードの記録は数えない（`src/core/records.ts`、画面は `#/records`）
- **遊びすぎの声かけ**：続けて遊んだ時間が決めた時間をこえると、結果が出たときに「ちょっと きゅうけい しよう」（`src/core/playtime.ts`）
- **遊ばれた回数の集計（匿名）**：公開版でだけ、できごととゲーム名・リンクの印（`?src=`）・ホーム画面から開いたか・アプリの版を送る。名前・点数・端末ID・Cookie は送らない。送り先は `site.config.json` の `counterUrl`＝ソフトテニスIQの数値シートの GAS（別リポジトリ stiq-metrics、リンク遷移と同じ受け口 URL）。`app=softtennis-asobi` の行はシートの asobi_events に入り、タブ「ミニゲーム」でゲーム別に数える。ゲームを足したら stiq-metrics の CONFIG.ASOBI.GAMES にも足す（`src/core/counter.ts`）
- **リンクの印**：Instagram のプロフィール `?src=st_ig_bio`、ソフトテニスIQから `?src=st_iq_cross`、きねんカード `?src=share`
- **おうちの方へ**（`#/parents`、保護者の確認つき）：遊び方・この端末の記録・集計の説明とオンオフ・アプリの紹介・記録を消す

## 使い方

```bash
npm install
npm run dev        # http://localhost:5173/softtennis-asobi/
npm test           # ルール・物理・早押し・問題のテスト（Vitest）
npm run test:e2e   # スマホ・タブレットの大きさで2人同時のタッチなど（Playwright）
npm run build      # dist/ に出力（sw.js に事前キャッシュの一覧を埋め込む）
```

ルールドリルの問題を取りこみ直す：`node scripts/import-drill.mjs`（元はソフトテニスIQの `src/tools/drill/questions.ts`。問題は元の方で直す）

## 声（ElevenLabs）

読み上げの声は ElevenLabs で**前もって** mp3 にして `public/voice/` に置く。遊ぶ最中は通信しない。mp3 が無いセリフは、端末の読み上げ（speechSynthesis）で読む。
ホークアイ先生の声はまだ決めていない（候補を作って本人が選ぶ）。

```bash
npm run voice:dry        # 作るセリフと文字数を見る（API は呼ばない）
npm run voice            # まだ無いセリフだけ作る
```

## 画像

- ホークアイ先生は**原画をそのまま使う**（描き直さない）。`art/` の原画から、背景を抜いた絵（`public/hawk/cut-*.png`）と顔のバッジ・アイコンを作る：`npm run art`
- 表情が足りない分（びっくり・しまった・走る）は、いまは近い原画で代わりにしている（`scripts/build-art.mjs` の FALLBACK）。本人が ChatGPT で同じ画風の表情を作ったら `art/` に足す
- リンクを貼ったときの画像（OGP、`public/ogp.png`）：開発サーバーを 5181 番で起動してから `node scripts/build-ogp.mjs public`

## 方針

- 子ども向けなので、外部に送るのは匿名の回数だけ（公開版・保護者が止められる）。記録・ほし・きせかえは端末の中だけ。共有の前に保護者の確認を出す
- 保存のキーは `softtennis-asobi:` で始める（ピクルくんとあそぼと同じ omicreate.github.io に置くため）
- 画面は「縦長の舞台」を基準に作り、横向きなら 90° 回す。上の人の文字は 180° 回す（`src/core/Stage.tsx`）
- 物理・ルール・早押しの判定は React に依存しない純粋な関数にして、テストで確かめる
- 用語はソフトテニスIQの用語ルールどおり（コースは 正クロス／逆クロス／右ストレート／左ストレート、「ハーフボレー」は使わない）
- ラケットはグリップエンドを体の横で握り、構え→テイクバック→インパクト→フォロースルーで回す（`src/games/rally/draw.ts`）
